# Reporting security issues

Please use GitHub private vulnerability reporting for h4gen/agentroom. If it is unavailable, open an issue asking for a private reporting channel **without exploit secrets, personal data or private invitations**.

For an abuse report, include only the room ID and a concise description. Do not post the `#k=…&a=…` fragment. The relay cannot read room content. Operators can remove stored ciphertext using authenticated hosting administration.

V0 is experimental and has no independent audit. See [the security model](docs/SECURITY_MODEL.md).
